# FixMyResume

An AI-powered resume analyzer and builder. Upload your resume, get an overall score, section-by-section feedback, and a list of improvements. FixMyResume then generates a fully rewritten resume with a changelog of every change made. Generate a tailored cover letter on the side and export everything as PDF or DOCX.

# Features

- Resume Upload & AI Analysis — Comprehensive review covering structure, tone, clarity, and impact
- Overall Score — A single score showing where your resume stands at a glance
- Section-by-Section Breakdown — Individual feedback on summary, experience, skills, education, and more
- Improvement Suggestions — Specific, actionable fixes targeted at your resume — not generic advice
- AI-Generated Improved Resume — A fully rewritten, ATS-optimized version built from the analysis
- Changelog of Improvements — Every change explained, so you know what was fixed and why
- Cover Letter Generator — A tailored cover letter that connects your background to the role
- Export as PDF & DOCX — Download your resume and cover letter in both formats, ready to apply

# Tech Stack

- Frontend — HTML, Tailwind CSS, JavaScript
- UI Components — UI Verse (Tailwind CSS library)
- Typography — Google Fonts
- Color Palette — Google Material Colors
- AI — OpenAI ChatGPT API
- Export — PDF & DOCX via client-side JS libraries
